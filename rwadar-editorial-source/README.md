# Portadas editoriales de RWAdar

Estas 26 imágenes maestras se generaron con ImageGen integrado en Codex para explicar visualmente el tipo de activo o servicio asociado a cada plataforma. Son representaciones editoriales de RWAdar: no muestran necesariamente un activo, cliente, operación o producto concreto de la empresa.

La aplicación identifica cada una como `Ilustración`; no publica imágenes de terceros como portadas. Las versiones publicadas se convierten a WebP y se exportan sin metadatos. El lote inicial usa 720 × 720 px; las tres sustituciones del 21 de septiembre de 2026 usan 640 × 440 px para priorizar la imagen en la tarjeta compacta.

## Dirección visual y prompt común

Fotografía editorial hiperrealista y premium, formato 1:1, paleta grafito y verde bosque, iluminación esmeralda coherente con RWAdar, activo completo dentro del área central y tokenización representada únicamente mediante pequeñas teselas de vidrio. Sin texto, letras, números, precios, rentabilidades, símbolos monetarios, logotipos, capturas de pantalla, gráficas, flechas, personas identificables, marcas de agua ni criptomonedas reconocibles.
