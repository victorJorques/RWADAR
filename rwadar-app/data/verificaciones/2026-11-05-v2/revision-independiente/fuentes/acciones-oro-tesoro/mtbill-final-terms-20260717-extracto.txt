                                                     Ethereum is a public blockchain supporting the native
                                                     cryptocurrency Ether (ETH) and the execution of smart
                                                     contracts. It is an Ethereum Virtual Machine (EVM)-
                                                     compatible network. The EVM is the software environment in
                                                     which smart contracts and decentralized applications are
                                                     written and executed, enabling the issuance and transfer of
                                                     digital tokens. Transactions are validated through a Proof-of-
                                                     Stake consensus mechanism by independent validators.

                                                     Base is an EVM-compatible Layer 2 blockchain built on
                                                     Ethereum. It enables the execution of smart contracts and
                                                     digital token transactions while relying on Ethereum for
                                                     security and settlement. Base operates as an Optimistic Rollup.

                                                     Oasis Sapphire is an EVM-compatible blockchain providing
                                                     confidential smart contract execution through Trusted
                                                     Execution Environments (TEEs). It operates as part of the
                                                     Oasis Network, which uses a Proof-of-Stake consensus
                                                     mechanism.

                                                     Algorand is a public Layer 1 blockchain supporting digital
                                                     assets and smart contracts. It uses a Pure Proof-of-Stake
                                                     consensus mechanism in which validators are selected through
                                                     cryptographic sortition.

                                                     Plume is an EVM-compatible blockchain designed for
                                                     tokenized real-world assets and decentralized finance
                                                     applications. It supports smart contracts and digital token
                                                     issuance and operates using a Proof-of-Stake validator
                                                     network.

                                                     Rootstock (RSK) is an EVM-compatible smart contract
                                                     platform secured by Bitcoin through merge mining. It enables
                                                     the issuance and execution of smart contracts while leveraging
                                                     Bitcoin's mining network for consensus.
