# RWAdar · ficha de alta de patrocinador

> Plantilla de la alternativa anterior de cuota fija, no seleccionada. Para
> comisiones usar el cuestionario de clasificación y el acuerdo por conversión.

Esta ficha se completa antes de preparar o publicar una campaña. Un campo vacío
no se interpreta como aprobado: bloquea el elemento al que afecta.

Es una plantilla versionada: no se rellena en este archivo. La ficha de cada
empresa se conserva fuera de Git en el expediente privado con control de acceso
y en el repositorio solo queda, cuando corresponda, una referencia no sensible.

## F. Control previo a publicación

- [ ] Contrato final firmado por personas con capacidad.
- [ ] Titular y datos de facturación de RWAdar completos.
- [ ] Proveedor identificado y contrastado.
- [ ] Registro o licencia comprobado en fuente oficial cuando aplica.
- [ ] Oferta vigente y disponible en la jurisdicción declarada.
- [ ] Precio, costes y cifras contrastados en fuente primaria.
- [ ] Todas las imágenes tienen permiso comercial documentado.
- [ ] Enlace HTTPS canónico y sin parámetros de seguimiento no aprobados.
- [ ] Etiqueta Patrocinada visible en tarjeta, detalle y enlace.
- [ ] Ranking y criterio editorial sin cambios por el contrato.
- [ ] Privacidad, aviso legal, riesgos y términos coherentes.
- [ ] QA de escritorio, móvil, accesibilidad, caché y enlaces completado.
- [ ] Responsable de rollback identificado.
- [ ] Pago y publicación usan aprobaciones independientes.
- [ ] Cualquier devolución vuelve solo al método de pago original.
