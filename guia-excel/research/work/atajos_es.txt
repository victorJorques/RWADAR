 - Seleccionar la pestaña activa de la cinta de opciones y activar las teclas de acceso. => Alt+Tecla del logotipo de Windows. Para ir a otra pestaña, use las tec
 - Mover el foco a comandos en la cinta. => Entrar y, luego, TAB o Mayús+TAB
 - Activar el botón seleccionado. => Barra espaciadora o Entrar
 - Úselo para abrir la lista de un comando seleccionado. => Barra espaciadora o Entrar
 - Abrir el menú de un botón seleccionado. => Alt+flecha abajo
 - Cuando un menú o submenú está abierto, úselo para moverse al siguiente comando. => Esc

## Métodos abreviados de teclado para la edición de celdas
 - Para realizar esta acción => Pulse
 - Insertar una fila encima de la actual => Alt+Windows logo key+H, I, R
 - Insertar una columna a la izquierda de la columna actual => Alt+Windows logo key+H, I, C
 - Cortar selección. => Ctrl+X
 - Copiar selección. => Ctrl+C
 - Pegar selección => Ctrl+V
 - Deshacer una acción. => Ctrl+Z
 - Rehacer una acción => Ctrl+Y
 - Úselo para comenzar una nueva línea en la misma celda. => Alt+Entrar
 - Insertar un hipervínculo. => Ctrl+Alt+K
 - Insertar una tabla. => Ctrl+I
 - Úselo para insertar una función. => Mayús+F3
 - Aumentar el tamaño de la fuente. => Ctrl+Mayús+corchete angular de cierre (>)
 - Reducir el tamaño de la fuente. => Ctrl+Mayús+corchete angular de apertura (<)
 - Aplique un filtro. => Alt+Windows logo key+A, T
 - Reaplicar un filtro => Ctrl+Alt+L
 - Active y desactive Autofiltro . => Ctrl+Mayús+L

## Métodos abreviados de teclado para la inserción de datos
 - Para realizar esta acción => Pulse
 - Completar la escritura de la celda y seleccionar la celda de abajo => Entrar
 - Completar la escritura de la celda y seleccionar la celda de arriba => Mayús+Entrar
 - Completar la escritura de la celda y seleccionar la siguiente celda en la fila => Tecla TAB
 - Completar la escritura de la celda y seleccionar la celda anterior en la fila => Mayús+TAB
 - Cancelar la entrada de celda => Esc

## Métodos abreviados de teclado para la edición de datos en celdas
 - Para realizar esta acción => Presione
 - Editar la celda seleccionada => F2
 - Recorrer todas las distintas combinaciones de referencias absolutas y relativas cuando se  => F4
 - Editar la celda seleccionada => Eliminar
 - Borrar la celda seleccionada y empezar a editar => Retroceso
 - Ir al principio de línea de celda => Inicio
 - Ir al final de línea de celda => Fin
 - Seleccione a la derecha por un carácter. => Mayús+Flecha derecha
 - Seleccionar hasta el principio de datos de celda => Mayús+Inicio
 - Seleccione hasta el final de los datos de la celda. => Mayús+Fin
 - Seleccione a la izquierda un carácter. => Mayús+Flecha izquierda
 - Extender la selección a la última celda que no esté en blanco de la misma columna o fila q => Ctrl+Mayús+Flecha derecha o Ctrl+Mayús+Flecha izquierda
 - Insertar la fecha actual. => Ctrl+punto y coma (;)
 - Insertar la hora actual. => Ctrl+Mayús+Punto y coma (;)
 - Copiar la fórmula de la celda superior => Ctrl+apóstrofo (')
 - Copiar el valor de la celda superior => Ctrl+Mayús+Apóstrofo (')
 - Inserta un argumento de fórmula. => Ctrl+Mayús+A

## Métodos abreviados de teclado para mover y desplazarse dentro de hojas de cálculo
 - Para realizar esta acción => Pulse
 - Moverse hacia arriba una celda. => Flecha arriba o Mayús+Entrar
 - Moverse hacia abajo una celda. => Flecha abajo o Entrar
 - Moverse hacia la derecha una celda. => La tecla TAB o la tecla de flecha derecha
 - Ir al principio de la fila => Inicio
 - Ir a la celda A1 => Ctrl+Inicio
 - Ir a la última celda del rango utilizado => Ctrl+Fin
 - Bajar una pantalla (28 filas) => Página abajo
 - Subir una pantalla (28 filas) => Página arriba
 - Desplazarse hasta el extremo de la región de datos actual. => Ctrl+Flecha derecha o Ctrl+flecha izquierda
 - Mover entre la cinta de opciones y el contenido del libro => Ctrl+F6
 - Desplazarse a una pestaña diferente de la cinta de opciones => Tecla TAB Presione Entrar para ir a esa pestaña de la cinta.
 - Insertar una nueva hoja => Mayús+F11
 - Pasar a la pestaña siguiente => Ctrl + Alt + AV Pág
 - Cambie a la siguiente hoja (cuando se encuentra en Microsoft Teams o en un explorador dist => Ctrl+Av Pág
 - Pasar a la pestaña anterior => Ctrl + Alt + Re Pág
 - Cambiar a la hoja anterior (en Microsoft Teams o en un explorador distinto de Chrome). => Ctrl+Re Pág

## Métodos abreviados de teclado para trabajar con objetos
 - Para realizar esta acción => Pulse

 - Cierre el menú o explore en profundidad. => Alt+tecla de dirección arriba
 - Seguir hipervínculo => Ctrl+Entrar

## Métodos abreviados de teclado para trabajar con celdas, filas, columnas y objetos
 - Para realizar esta acción => Pulse
 - Seleccione un rango de celdas. => Mayús+Teclas de dirección
 - Seleccionar una columna completa => Ctrl+barra espaciadora
 - Seleccionar toda una fila => Mayús+barra espaciadora
 - Extender la selección a la última celda que no esté en blanco de la misma columna o fila q => Ctrl+Mayús+Flecha derecha o Ctrl+Mayús+Flecha izquierda
 - Agregue una celda o un rango de celdas no adyacentes a una selección de celdas => Mayús+F8
 - Inserta celdas, filas o columnas. => Ctrl+Signo más (+)
 - Eliminar celdas, filas o columnas => Ctrl+signo menos (-)
 - Ocultar filas => Ctrl+9
 - Mostrar filas => CTRL+Mayús+9
 - Ocultar columnas => Ctrl+0
 - Mostrar columnas => CTRL+Mayús+0

## Métodos abreviados de teclado para moverse dentro de un rango seleccionado
 - Para realizar esta acción => Pulse
 - De arriba a abajo (o hacia delante en la selección) => Entrar
 - Desplazarse de abajo a arriba (o volver a través de la selección). => Mayús+Entrar
 - Mover hacia delante en una fila (o hacia abajo a través de una sola columna de selección) => Tecla TAB
 - Mover hacia atrás en una fila (o hacia arriba a través de una selección de una sola column => Mayús+TAB
 - Desplazarse a una celda activa. => Mayús+Retroceso
 - Se desplaza a la celda activa y mantiene la selección. => Ctrl+Retroceso
 - Girar la celda activa a través de las esquinas del rango seleccionado => Ctrl+Punto (.)
 - Desplazarse al siguiente rango seleccionado => Ctrl + Alt + Flecha derecha
 - Desplazarse al anterior rango seleccionado => Ctrl + Alt + Flecha izquierda
 - Extender la selección a la última celda de la hoja => Ctrl+Mayús+Fin
 - Extender la selección a la primera celda de la hoja => Ctrl+Mayús+Inicio

 - Actualizar todos los datos externos => Ctrl+Alt+F5

## Copilot en Excel
 - Para realizar esta acción => Usar
 - Envíe su indicación en el panel de tareas de Copilot en Excel. => Entrar o Entrar
 - Detener o cancelar la solicitud de Copilot en Excel. => Esc
 - Acepta los cambios realizados por Copilot en Excel. => Ctrl+Entrar o Cmd+Retorno
 - Cambiar entre el modo de edición, chat y plan en el panel de tareas de Copilot en Excel. => Ctrl+Mayús+M o Cmd+Mayús+M
 - Navegue entre las respuestas del chat en el panel de tareas de Copilot en Excel. => Alt+C u Opción+C
 - Confirme el uso de los archivos seleccionados en el panel de tareas de Copilot en Excel. => Ctrl+J o Cmd+J
 - Inicie el dictado de Copilot en Excel. => Alt+Mayús+H u Opción+Mayús+H
 - Abra el panel de tareas de Copilot en Excel. => Alt+C o Cmd+Ctrl+I
 - Mover el foco entre la cuadrícula de Excel y el panel de tareas de Copilot en Excel. => F6 o Mayús+F6

## Menú de accesos directos de accesibilidad
 - Para realizar esta acción => Presionar
 - Cíclico entre regiones de punto de referencia. => CTRL + F6 o CTRL + Mayús + F6
 - Moverse dentro de una región de punto de referencia. => Tecla TAB o Mayús+TAB
 - Vaya al campo de búsqueda para ejecutar cualquier comando. => Alt+Q
 - Mostrar u ocultar sugerencias clave o acceder a la cinta de opciones => Alt+Tecla del logotipo de Windows.
 - Editar la celda seleccionada => F2
 - Ir a una celda específica => Ctrl+G
 - Desplazarse a otra hoja de cálculo del libro. => CTRL + Alt + Retroceder Página o CTRL + Alt + Avanzar página
 - Abrir el menú contextual. => Mayús+F10 o tecla de menú de Windows
 - Leer encabezado de fila => CTRL + Alt + Mayús + T
 - Leer fila hasta la celda activa => CTRL + Alt + Mayús + Inicio
 - Leer fila a partir de la celda activa => CTRL + Alt + Mayús + Fin
 - Leer encabezado de columna => CTRL + Alt + Mayús + H
 - Leer columna hasta la celda activa => CTRL + Alt + Mayús + Retroceder Página
 - Leer columna a partir de la celda activa => Ctrl+Alt+Mayús+Re Pág
 - Abra una lista de opciones de movimiento dentro de un cuadro de diálogo. => Ctrl+Alt+Barra espaciadora
